TapeDecay

Design concept

An acid-etched bronze pedal. The faceplate artwork — etched cassette, city skyline, circuit traces, 夜の街 — is mounted as an image texture on real 3D geometry in Blender: controls are physical objects rendered on top of it, casting true contact shadows onto the etching; the speed slot is a boolean hole machined through the textured plate with a neon track inside. One scene, one light rig — no compositing seams. Every indicator glows retro-cyan against the patina.

Components

Each control is a separately rendered asset under a rig matched to the plate — warm key, cool fill, and a cyan rim light that ties the hardware to the neon.

The signal

Plots generated from the shipping DSP code itself — the same loss-filter design and the same Jiles-Atherton solver that run in the plugin.

The playback-loss filter. Speed moves every physical mechanism at once — half the speed and the whole curve slides down an octave. Age only widens the head-tape gap, tilting the spectrum ever steeper (Wallace's 54.6·d/λ dB law).

The mechanical layer: slow wow (0.7 Hz) and fast flutter (8 Hz) bend pitch like a worn transport, and dropouts fade in over ~70 ms and breathe back over ~120 ms — shared across channels, like a real patch of shed oxide passing the head.

Audio engine

Physical tape model only — no shortcut waveshaper. The chain, per block:

  • Level-true: an end-of-chain linked-RMS stage matches wet loudness to the dry input (~150 ms, stereo-linked) — Sat and Speed change tone, not volume.
  • Real-time safe: no allocation, locks or filter design on the audio thread; loss-FIR redesign runs on the message thread behind an atomic double-buffer.
  • Default voicing: −2.6 dB @ 3 kHz, −5.6 dB @ 6 kHz at 7.5 ips — warm tape, not a broken deck.
  • Formats: VST3 · AU · Standalone, macOS universal + Windows x64, built by CI.
